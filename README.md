## 📖 What's a "Sessional"?

In the Bangladeshi engineering curriculum system, most theory courses are paired with a **sessional course** — a lab-based companion course focused on implementing, testing, and reporting on what's taught in the theory class. Sessionals are typically graded through lab reports, code submissions, and viva voce (oral) exams rather than a single written final.
